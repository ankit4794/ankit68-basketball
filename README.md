# ANKIT68°

A street-basketball training program landing page with an original, procedurally-textured Three.js basketball (no external 3D model or textures — the leather/seam texture is drawn on a canvas at runtime).

## Stack
Vanilla HTML/CSS/JS, Three.js (module CDN), Motion (motion.dev) for scroll reveals and spring hover/press interactions, Google Fonts (Poppins).

## Run locally
```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Notes
- The trial-session form is a front-end-only demo — submissions are not sent anywhere.
- All contact details (address, phone, email) are placeholders.
